# 🌍 Deforestation Monitoring Demo Model

A Python-based demo project that simulates NDVI-based deforestation detection using satellite-like imagery. The system identifies vegetation loss between two dates and visualizes affected areas on interactive maps and plots.

Note: This project uses simulated data and is intended for learning and prototyping.

## Features

NDVI-based change detection

Single-region monitoring

Interactive map and visualizations

Deforestation patch analysis

CSV export of results

## Tech Stack

Python, NumPy, Pandas, Matplotlib, Folium, scikit-image, Plotly

## Usage

Run in Jupyter Notebook / Google Colab, select a region and dates, then execute monitoring.
